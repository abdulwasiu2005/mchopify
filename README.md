# Mchopify 🍲

A responsive restaurant menu and food ordering web application built with Next.js. Mchopify allows customers to browse meals, filter menu categories, manage a shopping cart, and complete a simulated checkout experience.

## Features

- Browse food items across different categories.
- Filter the menu by category.
- View meal images, descriptions, prices, and availability.
- Add available meals to the cart.
- Increase, decrease, or remove items from the cart.
- View cart quantities and subtotal.
- Responsive layout for desktop, tablet, and mobile devices.
- Dedicated cart view on smaller screens.
- Checkout form for customer name, phone number, and delivery address.
- Order confirmation simulation.

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- pnpm

## Getting Started

### Prerequisites

- Node.js
- pnpm

### Installation

Clone the repository:

```bash
git clone https://github.com/abdulwasiu2005/mchopify.git
```

Navigate into the project directory:

```bash
cd mchopify
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Limitations

This project is a frontend practice application. The checkout and order confirmation are simulated.

- Orders are not saved to a database.
- No real payment processing is implemented.
- Cart contents are not persisted after refreshing the page.

## Purpose

Built as a portfolio project to practice React, Next.js, TypeScript, component-based development, state management, responsive design, and frontend application workflows.
